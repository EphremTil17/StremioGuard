# v0.4.0 (2026-11-16)

A security release. An architecture audit, a code audit and a five-part security audit
reviewed the stack, and this release fixes what they found: the VPN guard, the network
boundary, Comet's patches, input handling, the gateway, the containers and the files on the
host. It also keeps the watchdog supervised through long outages, and automates Comet and
Stremio updates. It covers every change since v0.3.53.

## Upgrading

- **Deploy:** `./stremio stop`, then `./stremio start`. Every container is recreated, gluetun
  included, so the tunnel reconnects. `start` does not restart a watchdog that is already
  running; after a Python-only change, run
  `systemctl --user restart stremioguard-watchdog.service`.
- **Postgres password:** if Comet's database still uses the legacy password, rotate it while the
  stack is stopped: `./stremio comet rotate-db-password`. Postgres now listens on `127.0.0.1`
  only and requires the password.
- **gluetun settings in `.env`:** the HTTP proxy, Shadowsocks, control-server auth, firewall
  ports and `FIREWALL_OUTBOUND_SUBNETS` are pinned in `docker-compose.yml`; `start` warns when
  `.env` tries to set them. LAN access from the VPN namespace is no longer supported.
- **Gateway tokens** reach only the addon routes: manifest, stream, playback and configure.
  Everything else, Comet Sync, ChillLink, admin and torznab included, returns 403, and tokens
  match exactly, case included.
- **`.env` values** containing line separators (U+2028, vertical tab, form feed and the like) are
  refused instead of being split into extra keys.
- **`.stremio` and `logs`** must be real directories; a symlink in their place is refused.
- **`./stremio comet vendor-sync` is gone.** Patches render from the Comet image's own source,
  and the untracked `vendor/comet` checkout can be deleted.

## Security

- **VPN guard** (`2de2bc7`, `3183952`):
  - an IP-check service that hangs or answers garbage no longer crash-loops the watchdog into a
    lockout;
  - the leak check compares like with like (IPv4 against IPv4, `::ffff:` addresses unwrapped);
  - an IP check that answers with a private, loopback or other non-public address counts as no
    answer;
  - leaks that come and go now lock out;
  - a lockout can no longer be lost through an unwritable marker file;
  - `start` stops services that are already running when the verdict is UNSAFE or UNKNOWN.
- **Network boundary** (`4d65782`):
  - Docker's embedded DNS is blocked inside the tunnel's namespace;
  - raw packet sockets are dropped from every service;
  - Postgres listens on loopback and requires its password;
  - `--deep` validation boots the candidate Comet with no network.
- **Comet** (`c8e316f`, `3b85558`, `af617b1`):
  - P2P streams are blocked whatever the addon configuration asks;
  - a response guard strips magnets and info hashes at Comet's response boundary, for every
    JSON media type;
  - torznab is closed;
  - the Postgres password no longer appears in Comet's log.
- **Input** (`1d5554b`, `3183952`):
  - `.env` and `gluetun.env` refuse line separators;
  - Comet images with symlinks or special files in their source tree are refused;
  - `COMET_IMAGE` must be a valid image reference;
  - NordVPN responses are size-capped, and a cached server is used for at most 24 hours after a
    failed lookup.
- **Gateway** (`a48ba74`, `b1fc201`):
  - addon-only, exact-match tokens;
  - client IP headers are cleared before Comet sees them, and an invalid Host gets 400;
  - `/admin` and `/kodi` are blocked in every encoding;
  - request lines carrying a token are masked in the access log;
  - token rotation is atomic.
- **Containers** (`6647b86`): `no-new-privileges` on every service, all capabilities dropped
  except the few each image needs, and read-only root filesystems for Comet, StremThru and the
  gateway.
- **Host files** (`3183952`):
  - everything under `.stremio`, `logs` and `.env` is private from creation;
  - state files are read without following links or blocking on a FIFO;
  - logged tracebacks no longer dump variable values.

## Added

- `./stremio comet rotate-db-password` and `./stremio comet gateway-reload` (`4d65782`,
  `b1fc201`).
- `start` and `restart` check that Comet runs the expected image and bundle files, recreate it
  once if they are stale, and reload the gateway with a checked `nginx -t` (`af617b1`).
- `./stremio comet status` shows the active image, its source revision and the tested digest.
- A gateway liveness check on a loopback-only listener (port 8099), replacing `nginx -t`
  (`6647b86`).
- An uncached-result marker (🔸) on Comet's stream names (`c8e316f`).
- `scripts/lab.py`, an offline test lab for the gateway and the Comet patches (`6647b86`).
- CI builds the Stremio image with its patches; Dependabot's Stremio updates and the Comet
  canary's validated bumps merge on their own when their checks pass, and their branches are
  deleted after the merge.

## Changed

- **Watchdog supervision** (`5e8d4a8`): it now reports to systemd before each bounded step of a
  check, so a long outage no longer gets it killed, while a step that hangs still does. NordVPN
  lookups and alerts have hard total deadlines, and IP checks are capped at 60 seconds.
- **Watchdog robustness** (`4640e8c`):
  - after gluetun restarts on its own, the services rejoin its new network namespace;
  - the CLI and the watchdog take turns on the stack;
  - a repeated leak verdict trips the circuit breaker;
  - `start` no longer recreates a healthy gluetun for a new server recommendation;
  - `start` publishes a generation of the configuration under `.stremio/`, so `.env` edits
    apply when they are made.
- **Quieter logs** (`c6a0f68`): a watchdog summary is written only when something happened, plus
  an hourly heartbeat; an unreachable IP checker warns at most every five minutes.
- **Shutdown** falls back to `docker stop` when Compose cannot list or stop the protected
  services (`a48ba74`).
- **StremThru's `torz` feature** is enabled again, restoring the routes Comet plays through
  (`c8e316f`).
- **Dependabot** watches only the images; Python packages and GitHub Actions are updated by hand.
- **Documentation:** the README is now a short overview, and the details moved into `docs/`: setup,
  operations, the watchdog, Comet and the security model, indexed in `docs/README.md`. Linux is
  the primary platform; WSL2 is covered in the setup guide, and the CLI's hints no longer assume
  WSL.
