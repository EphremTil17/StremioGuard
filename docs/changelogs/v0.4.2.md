# v0.4.2 (2026-11-18)

A security and maintenance release. It pins the gateway to `nginx:1.31.9-alpine` for HTTP/2 CVE
fixes, closes the Gunicorn/Uvicorn log-scrubbing bypass and middleware/proxy gaps found during deep
auditing, hardens `metadata.py` and the Stremio forwarded-header patch, adds reproducible
per-domain unit coverage reporting, and trims and updates the documentation set.

## Upgrading

- **Deploy:** `./stremio stop`, then `./stremio start`. This recreates `comet-gateway` on the
  pinned `nginx:1.31.9-alpine` digest and applies the updated Comet override bundle (now 16 specs,
  including `overrides/admin.py`).

## Security

- **Gateway (`docker-compose.yml`):** pinned `comet-gateway` to `nginx:1.31.9-alpine` by digest to
  remediate upstream HTTP/2 vulnerabilities.
- **Comet log scrubbing (`overrides/comet_log_scrubber.py`):** wrapped
  `logging.StreamHandler.format` inside `_sg_route_stdlib_logging()` so `gunicorn.error` and
  `uvicorn.error` loggers with `propagate=False` cannot emit unscrubbed secrets or tracebacks.
- **Comet middleware & admin (`overrides/response_guard.py`, `overrides/admin.py`):**
  - capped buffered response inspection (`sniff` and `inspect`) at 16 MiB, returning `502` on
    overflow instead of buffering unbounded upstream bodies;
  - routed `POST /s/<PUBLIC_API_TOKEN>/configure/login` through the same `_LoginBudget` rate
    limiter as `/configure/login`;
  - added baseline browser security headers (`X-Content-Type-Options`, `X-Frame-Options`,
    `Referrer-Policy`, `Content-Security-Policy`, `Permissions-Policy`) to direct Comet responses;
  - added `overrides/admin.py` (`Requirement.REQUIRED`) so the `admin_session` cookie sets `Secure`
    when `X-Forwarded-Proto: https` is present behind a TLS-terminating portal.
- **Cinemeta metadata lookup (`metadata.py`):** validated IMDb IDs (`^tt\d{1,12}$`) and non-negative
  integer seasons, bounded the episode-count cache to 1,024 entries (LRU + TTL), disabled
  redirects, used `PublicOnlyConnector` inside Comet, and streamed responses via
  `iter_chunked(65536)` with a 2 MiB hard cap.
- **Stremio patch (`docker/stremio/patch-server.js`):** strictly validated `X-Forwarded-Proto`,
  `Host`, and `X-Forwarded-Prefix` before deriving the streaming server URL.
- **Comet image validation (`comet/validation.py`, `comet/smoke_probe.py`):** ran
  `import_smoke_test` with `--cap-drop ALL`, `--security-opt no-new-privileges:true`,
  `--read-only`, and a sized `noexec,nosuid,nodev` `/tmp` tmpfs; extended smoke probes to verify
  security headers, prefixed login pacing, `_is_secure_request`, and `POST /admin/login` route
  binding.

## Added

- `scripts/coverage_by_domain.py` and `pytest-cov` dev dependency to reproduce line+branch unit
