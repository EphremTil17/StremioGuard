# v0.4.1 (2026-11-17)

A security release. It hardens edge cases across Comet's logs, the stream proxy, the gateway, the
Stremio server, the containers and the host's units. It also adds a way to send the public
configure page to the owner's own login portal. It covers every change since v0.4.0.

## Upgrading

- **Deploy:** `./stremio stop`, then `./stremio start`. Every protected service is recreated
  with its new limits; gluetun is recreated once to gain its init process, so the tunnel
  reconnects.
- **The configure page is off the public address.** Comet's `/configure` (and Stremio's
  Configure button for a gateway token) now returns 403 on the public gateway. Choose one:
  - set `COMET_GATEWAY_CONFIGURE_URL` to a portal behind its own login, such as a Cloudflare
    Access application (see `docs/comet-gateway.md`), and the public addresses redirect there;
  - open it on the host through `COMET_HOST_PORT`, for example over `ssh -L`;
  - or set `COMET_GATEWAY_PUBLIC_CONFIGURE=1` to serve it publicly as before.
- **Stremio needs credentials.** With the Stremio profile on, `start` refuses to run without
  `STREMIO_USERNAME` and `STREMIO_PASSWORD` (`STREMIO_ALLOW_NO_AUTH=1` opts out). Raw stream URLs
  then play only with those credentials or for a torrent a signed-in client already started; set
  `STREMIO_OPEN_RAW_STREAMS=1` if a player cannot start playback.
- **Request bodies over 64 KB** get 413 at the gateway. If a reverse proxy sits in front, set
  the same cap there (NPM: `client_max_body_size 64k;` in the host's Advanced tab).
- **Comet stream proxy connections** default to 10 per client instead of unlimited
  (`COMET_PROXY_MAX_CONNECTIONS`); `start` warns when the value is unlimited.
- **Comet configs** over 8 KB or with more than 10 debrid services are now invalid.

## Security

- **Comet's logs** (`284339d`, `04cc9e4`, `d38fb86`, `a4edc8d`):
  - every log sink, Python's library logging included, masks each credential setting's value,
    raw and URL-encoded, and the debrid keys of configs Comet has parsed;
  - URLs in logs keep only their scheme and host;
  - scraper errors never print an API key.
- **Comet's API** (`284339d`, `04cc9e4`, `3434620`):
  - CORS allows every origin without credentials;
  - the configure and admin logins are paced, each with its own budget;
  - forwarded prefix and host values are trusted only as plain values;
  - configs are size-bounded, and Comet caches at most 256 of them.
- **Stream proxy** (`04cc9e4`, `3434620`, `d38fb86`):
  - it connects only to public addresses: private, reserved and documentation ranges and their
    IPv6 forms are refused on every Python version;
  - it sends only the request's own headers upstream;
  - upstream errors reach the client as a status and a fixed message;
  - concurrent streams are counted per gateway token, and a request carrying a client-address
    header cannot claim a token's slots.
- **Gateway** (`284339d`, `8eb056d`, `3434620`, `d38fb86`):
  - the configure page is off the public address by default;
  - configure and admin login attempts share a limit of 6 a minute, however the path is spelled;
  - request bodies over 64 KB are refused;
  - every response carries `Content-Security-Policy`, `Permissions-Policy`, `nosniff`, frame
    denial and a same-origin referrer policy, and no nginx version;
  - credential grants from upstream responses are never passed through;
  - token-map writes are locked and ordered, so a concurrent reload or a failed write cannot
    restore a revoked token or admit an unlisted one.
- **Stremio server** (`04cc9e4`, `3434620`): credentials are required, and raw stream URLs
  need them or a torrent a signed-in client already started.
- **Containers** (`04cc9e4`): memory, process and tmpfs ceilings on every service; gluetun runs
  an init that reaps finished probe processes.
- **VPN guard** (`284339d`, `04cc9e4`):
  - a cached SAFE verdict counts only for the gluetun container it was checked in;
  - stop paths treat unexpected Compose output as possibly running, and also stop paused or
    restarting containers;
  - the gluetun auth-log scan follows elapsed time, so a clock change cannot hide new lines.
- **Host** (`284339d`, `8eb056d`, `04cc9e4`):
  - every `start` and `restart` removes group and other access from older files in `.stremio`
    and `logs`;
  - the systemd units run with `no-new-privileges` and related restrictions;
  - each publish ends with a hash manifest, and lifecycle commands refuse a mix of two
    generations;
  - the log canary never reads a file through a symlink or a FIFO, and its reads are capped.
- **CI** (`284339d`): actions are pinned to commit SHAs, and the Comet canary runs upstream code
  read-only, with writes in separate jobs.

## Added

- `COMET_GATEWAY_CONFIGURE_URL`: with a portal URL set, `/`, `/configure`, the
  token configure addresses and bare token addresses on the public gateway redirect to
  `<portal>/configure`. Invalid tokens still get 403. Setup asks for it, and
  `docs/comet-gateway.md` has a Cloudflare Access and tunnel template.
- `COMET_GATEWAY_PUBLIC_CONFIGURE=1` to serve the configure page publicly (`d38fb86`).
- `STREMIO_OPEN_RAW_STREAMS=1` to let raw stream URLs play without credentials (`3434620`).
- The import smoke test checks stream slots, config limits and config key masking against the
  real Comet image (`3434620`, `d38fb86`).

## Fixed

- The Stremio image's HLS converter and probe no longer reference an undefined variable
  (`04cc9e4`).
- The host test suite passes on Python 3.12, whose address tables predate RFC 9637.
